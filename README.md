# Release packages

Installable packages of the Glashaus widget set for testing, until it is published on npm.

Install in the ioBroker admin (Adapters → expert mode → install from custom URL) or in the console:

```
iobroker url https://raw.githubusercontent.com/djlex83/ioBroker.vis-2-widgets-glashaus/release-packages/iobroker.vis-2-widgets-glashaus-0.1.0.tgz
iobroker add vis-2-widgets-glashaus
```

Source code: branch `main`.
