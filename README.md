# Release packages

**The widget set is on npm now:** install `iobroker.vis-2-widgets-glashaus` (ioBroker admin → Adapters →
install from custom URL → tab *npm*, or `iobroker url iobroker.vis-2-widgets-glashaus` in the console), then add an
instance and restart vis-2. See the [README on `main`](https://github.com/djlex83/ioBroker.vis-2-widgets-glashaus#installation).

This branch only keeps the pre-release package 0.1.0 for those who installed it from here:

```
iobroker url https://raw.githubusercontent.com/djlex83/ioBroker.vis-2-widgets-glashaus/release-packages/iobroker.vis-2-widgets-glashaus-0.1.0.tgz
```

Source code: branch `main`.
